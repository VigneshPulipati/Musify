# Musify

Musify is a local-first music player built with React and Vite. It searches YouTube through a small local Python service powered by `yt-dlp`, resolves playable audio URLs on demand, and provides a focused library experience for queues, favorites, recently played tracks, and playlists.

All account and library data is kept in the browser's `localStorage`; there is no remote database or account service in this repository.

## Features

- Search for artists and songs through YouTube
- Stream search results in the in-browser audio player
- Play, pause, seek, adjust volume, and move through the queue
- Add tracks to favorites and recently played history
- Create playlists and add tracks to them
- Create and sign in to device-local accounts
- Persist the session, queue, current track, favorites, history, and playlists locally
- Use the responsive dark music-library interface without a remote backend database

## Requirements

- Node.js and npm
- Python 3
- `yt-dlp` installed in the Python environment used to run `server.py`

The frontend can be built without `yt-dlp`, but live search and playback require the local service and its Python dependency.

## Getting started

Clone or download the project, then install the frontend dependencies:

```powershell
npm install
python -m pip install yt-dlp
```

Start the local `yt-dlp` service in one terminal:

```powershell
python server.py
```

The service listens on `http://127.0.0.1:8765`.

Start the Vite development server in a second terminal:

```powershell
npm run dev
```

Open <http://localhost:5173> in a browser. Keep both processes running for live search and playback.

## Configuration

The frontend uses `http://127.0.0.1:8765` as the default API base URL. To point it at another compatible service, set `VITE_API_URL` before starting or building Vite:

```powershell
$env:VITE_API_URL = "http://127.0.0.1:8765"
npm run dev
```

The local service exposes the endpoints used by the frontend:

| Endpoint | Purpose |
| --- | --- |
| `GET /api/search?q=<query>` | Search YouTube and return up to eight track results |
| `GET /api/stream/<video-id>` | Resolve a best-audio stream URL for a video |

The built-in service only allows browser requests from `http://localhost:5173`.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server on port 5173 |
| `npm run build` | Create a production build in `dist/` |
| `npm run preview` | Preview the production build locally |

`npm run preview` serves only the frontend. The Python service must still be running when the application needs live search or playback.

## Data and privacy

Musify stores local accounts and library state in the browser that is running the app. Account passwords are converted to PBKDF2-SHA-256 hashes in the browser before storage, but this is still a device-local demo account system rather than production authentication. Clearing site data, changing browsers, or using another device removes or isolates that local state.

The Python service invokes `yt-dlp` to query YouTube and resolve audio URLs. Use Musify only with content you are permitted to access, and follow YouTube's terms and applicable content-owner restrictions.
